## Linear Algebra {#linear-algebra}

### Vector Spaces

**Definition**: A vector space V over a field F (usually ℝ or ℂ) is a set with:
- Vector addition: V × V → V
- Scalar multiplication: F × V → V
- Satisfying axioms (associativity, commutativity, distributivity, etc.)

**Examples**:
- ℝⁿ = {(x₁, ..., xₙ) : xᵢ ∈ ℝ}
- Function spaces: C∞(ℝ, ℝ) = smooth functions
- Matrix spaces: ℝᵐˣⁿ = m×n real matrices

### Linear Maps

**Definition**: f : V → W is linear if:
- f(v₁ + v₂) = f(v₁) + f(v₂)
- f(c·v) = c·f(v)

**Matrix representation**: With bases, f corresponds to a matrix A where f(v) = Av

### Inner Products

**Definition**: An inner product on V is a map ⟨·,·⟩ : V × V → ℝ that is:
- **Symmetric**: ⟨v,w⟩ = ⟨w,v⟩
- **Bilinear**: ⟨av₁+bv₂, w⟩ = a⟨v₁,w⟩ + b⟨v₂,w⟩
- **Positive definite**: ⟨v,v⟩ > 0 for v ≠ 0

**Standard inner product** on ℝⁿ: ⟨v,w⟩ = Σᵢ vᵢwᵢ

**Norm**: ‖v‖ = √⟨v,v⟩

### Eigenvalues and Eigenvectors

**Definition**: For linear map A : V → V:
- λ is an **eigenvalue** if there exists v ≠ 0 with Av = λv
- v is the corresponding **eigenvector**

**Characteristic polynomial**: det(A - λI) = 0

**Spectral theorem** (for symmetric matrices):
- Real eigenvalues
- Orthogonal eigenvectors
- Diagonal

izable

### Important Concepts for SCTT

- **Dual space**: V* = {linear maps V → ℝ}
- **Tensor products**: V ⊗ W
- **Exterior algebra**: ∧ᵏV (used for differential forms)
- **Matrix calculus**: Derivatives of matrix-valued functions

## Multivariable Calculus {#multivariable-calculus}

### Partial Derivatives

For f : ℝⁿ → ℝ, the **partial derivative** with respect to xᵢ:

∂f/∂xᵢ = lim_{h→0} [f(x + heᵢ) - f(x)]/h

where eᵢ is the i-th basis vector.

### Gradient

**Gradient** of f : ℝⁿ → ℝ:

∇f = (∂f/∂x₁, ∂f/∂x₂, ..., ∂f/∂xₙ)

- Points in direction of steepest increase
- Perpendicular to level sets

### Jacobian Matrix

For F : ℝⁿ → ℝᵐ, the **Jacobian**:

JF = [∂Fᵢ/∂xⱼ]ᵢⱼ (m × n matrix)

- Linearization of F at a point
- Used in chain rule

### Chain Rule

For F : ℝⁿ → ℝᵐ and G : ℝᵐ → ℝᵖ:

J(G ∘ F) = JG · JF

(Matrix multiplication of Jacobians)

### Taylor Series

For f : ℝⁿ → ℝ, expansion around point a:

f(x) = f(a) + ∇f(a)·(x-a) + ½(x-a)ᵀH(a)(x-a) + ...

where H = [∂²f/∂xᵢ∂xⱼ] is the Hessian matrix.

### Important Theorems

**Implicit Function Theorem**: If F(x,y) = 0 and ∂F/∂y ≠ 0, then locally y = g(x)

**Inverse Function Theorem**: If JF is invertible at a, then F is locally invertible

**Clairaut's Theorem**: Mixed partials commute: ∂²f/∂x∂y = ∂²f/∂y∂x (if continuous)

### Vector Calculus

**Divergence**: div F = ∇·F = Σᵢ ∂Fᵢ/∂xᵢ

**Curl** (in ℝ³): curl F = ∇×F = (∂F₃/∂y - ∂F₂/∂z, ...)

**Laplacian**: Δf = ∇²f = Σᵢ ∂²f/∂xᵢ²

**Fundamental theorems**:
- Gradient theorem: ∫_γ ∇f = f(b) - f(a)
- Divergence theorem: ∫_Ω div F = ∫_∂Ω F·n
- Stokes' theorem: ∫_Σ curl F = ∮_∂Σ F

## Topology {#topology}

### Topological Spaces

**Definition**: A topology on set X is a collection T of subsets (called open sets) such that:
1. ∅, X ∈ T
2. Arbitrary unions of open sets are open
3. Finite intersections of open sets are open

**Examples**:
- **Discrete topology**: All subsets are open
- **Metric topology**: Open balls Bᵣ(x) = {y : d(x,y) < r}
- **Standard topology on ℝ**: Generated by open intervals (a,b)

### Continuity

**Definition**: f : X → Y is continuous if preimages of open sets are open:
U open in Y  ⇒  f⁻¹(U) open in X

**Equivalent** (for metric spaces): lim_{x→a} f(x) = f(a)

### Connectedness and Compactness

**Connected**: Cannot be split into two disjoint non-empty open sets

**Path-connected**: Any two points can be joined by a continuous path

**Compact**: Every open cover has a finite subcover

**Heine-Borel** (for ℝⁿ): Compact ⟺ closed and bounded

### Manifolds (Informal)

**n-manifold**: Space that locally looks like ℝⁿ

**Examples**:
- Circle S¹ (1-manifold)
- Sphere S² (2-manifold)
- Torus T² (2-manifold)

**Charts**: Homeomorphisms φ : U → ℝⁿ for open sets U in the manifold

**Smooth manifolds**: Charts where transitions are smooth (C∞)

## Category Theory {#category-theory}

### Categories

**Definition**: A category C consists of:
- **Objects**: Ob(C) (often written as A, B, C ∈ C)
- **Morphisms**: For each A, B ∈ C, a set Hom(A,B) of arrows A → B
- **Composition**: f : A → B and g : B → C gives g ∘ f : A → C
- **Identity**: For each A, an identity id_A : A → A

**Axioms**:
- Associativity: h ∘ (g ∘ f) = (h ∘ g) ∘ f
- Identity: f ∘ id_A = f = id_B ∘ f

**Examples**:
- **Set**: Objects = sets, morphisms = functions
- **Grp**: Objects = groups, morphisms = group homomorphisms
- **Top**: Objects = topological spaces, morphisms = continuous maps
- **Type**: Objects = types, morphisms = functions (in type theory!)

### Functors

**Definition**: A functor F : C → D maps:
- Objects: A ∈ C ↦ F(A) ∈ D
- Morphisms: (f : A → B) ↦ (F(f) : F(A) → F(B))

Preserving composition and identities.

**Examples**:
- Forgetful functor: Grp → Set (forget group structure)
- Free functor: Set → Grp (free group on a set)
- Hom functor: Hom(A,−) : C → Set

### Natural Transformations

**Definition**: For functors F, G : C → D, a natural transformation α : F ⇒ G is:
- For each object A ∈ C, a morphism α_A : F(A) → G(A)
- **Naturality**: For f : A → B, the square commutes:
```
  F(A) ——F(f)——> F(B)
   |              |
  α_A            α_B
   |              |
   ↓              ↓
  G(A) ——G(f)——> G(B)
```

**"Natural" means**: Defined uniformly, independent of choices

### Adjoint Functors

**Definition**: F : C → D and G : D → C are adjoint (F ⊣ G) if:

Hom_D(F(A), B) ≅ Hom_C(A, G(B))

naturally in A and B.

**Examples**:
- Free ⊣ Forgetful (for groups, vector spaces, etc.)
- Product × ⊣ Exponential (in categories with products)

### Universal Properties

**Concept**: Defining objects by their relationships, not internal structure

**Example** (Product): A × B is universal for pairs:
- Projections π₁ : A × B → A, π₂ : A × B → B
- For any f : C → A, g : C → B, exists unique ⟨f,g⟩ : C → A × B

This perspective is central to type theory!

## Logic and Proof {#logic-and-proof}

### Propositional Logic

**Connectives**:
- ∧ (and), ∨ (or), → (implies), ¬ (not), ↔ (if and only if)

**Truth tables** define semantics

**Tautologies**: Always true (e.g., P ∨ ¬P, P → P)

### Predicate Logic

**Quantifiers**:
- ∀x. P(x) : "for all x, P(x) holds"
- ∃x. P(x) : "there exists x such that P(x)"

**Bound vs free variables**

**Substitution**: P(x)[t/x] = P(t) (replacing x with term t)

### Proof Techniques

**Direct proof**: Assume premises, derive conclusion

**Proof by contradiction**: Assume ¬P, derive contradiction, conclude P
- ⚠️ Not constructively valid!

**Proof by induction**:
- Base case: P(0)
- Inductive step: P(n) → P(n+1)
- Conclude: ∀n. P(n)

**Proof by cases**: P∨Q, prove R from both P and Q separately

### Constructive vs Classical Logic

**Classical logic**: Law of excluded middle (P ∨ ¬P) holds

**Constructive logic** (used in SCTT):
- Proofs must be constructive (provide witnesses)
- ¬¬P → P does not hold in general
- ∃x. P(x) requires producing an x

**Curry-Howard correspondence**:
- Propositions = Types
- Proofs = Programs
- Proof checking = Type checking

## Important Mathematical Structures for SCTT

### Groups

**Definition**: (G, ·, e) where:
- · : G × G → G (binary operation)
- e ∈ G (identity)
- Axioms: associativity, identity, inverses

**Examples**: (ℤ, +, 0), (ℝ*, ×, 1), permutation groups

### Rings and Fields

**Ring**: (R, +, ×) with two operations satisfying axioms

**Field**: Ring where every non-zero element has multiplicative inverse

**Examples**: ℤ (ring), ℚ, ℝ, ℂ (fields)

### Metric Spaces

**Definition**: (X, d) where d : X × X → ℝ₊ satisfies:
- d(x,y) = 0 ⟺ x = y
- d(x,y) = d(y,x)
- d(x,z) ≤ d(x,y) + d(y,z) (triangle inequality)

**Examples**:
- Euclidean metric: d(x,y) = ‖x - y‖
- Discrete metric: d(x,y) = 0 if x=y, 1 otherwise

### Normed Vector Spaces

**Norm** ‖·‖ : V → ℝ₊ satisfying:
- ‖v‖ = 0 ⟺ v = 0
- ‖cv‖ = |c|‖v‖
- ‖v + w‖ ≤ ‖v‖ + ‖w‖ (triangle inequality)

**Induces metric**: d(v,w) = ‖v - w‖

**Banach space**: Complete normed vector space

**Hilbert space**: Complete inner product space

## Common Notation

### Set Theory
- ∈ : element of
- ⊆ : subset
- ∪ : union
- ∩ : intersection
- ∅ : empty set
- ℘(X) : power set

### Number Systems
- ℕ = {0, 1, 2, ...} : natural numbers
- ℤ = {..., -1, 0, 1, ...} : integers
- ℚ : rational numbers
- ℝ : real numbers
- ℂ : complex numbers

### Functions
- f : X → Y : f is a function from X to Y
- f(x) or f x : function application
- dom(f) : domain
- codom(f) : codomain
- im(f) : image
- f⁻¹ : inverse function (if exists)

### Sequences and Series
- (aₙ)_{n=1}^∞ : sequence
- lim_{n→∞} aₙ : limit
- Σ_{n=1}^∞ aₙ : infinite series
- ∏_{n=1}^∞ aₙ : infinite product
